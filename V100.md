# V100 Server — Complete Setup & Run Guide

## Neuro-Neo4j on NVIDIA Tesla V100 Server (Volta Architecture)

**Author:** basakanimesh14  
**Hardware:** NVIDIA Tesla V100 — 5120 CUDA cores · 16 GB or 32 GB HBM2 · Volta architecture  
**Role in this project:** Primary training · Hyperparameter search · Multi-GPU DDP

---

## Hardware Snapshot

| Spec | V100 SXM2 / PCIe | Notes |
|---|---|---|
| CUDA cores | 5,120 | Volta architecture (SM 7.0) |
| Tensor cores | 640 (1st gen) | FP16 matrix multiply |
| VRAM | 16 GB or 32 GB HBM2 | **Dedicated** (not unified) |
| Memory bandwidth | 900 GB/s (SXM2) / 897 GB/s (PCIe) | |
| Precision | FP32, FP16 | **No BF16** (Volta predates BF16) |
| NVLink | 2× (SXM2) | Multi-GPU interconnect |
| TDP | 250–300 W | |
| Host OS | Ubuntu 18.04 / 20.04 / 22.04 | Standard x86_64 Linux |

> [!IMPORTANT]
> V100 (Volta) does **NOT** support BF16. Mixed precision must use **FP16** only.  
> This is already configured in `config/v100_config.yaml` — do not change to BF16.

> [!NOTE]
> Unlike AGX Orin, V100 has **dedicated VRAM** separate from system RAM.  
> `pin_memory=True` is beneficial here and is already set in the config.

Unlike AGX Orin, V100 uses standard x86_64 wheels from PyPI:

```bash

# e.g., release 12.1 → use cu121
# e.g., release 11.8 → use cu118

    --index-url https://download.pytorch.org/whl/cu121

# For CUDA 11.8:
# pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

## Step 10 — Run ETL

```bash
python3 - <<'PYEOF'
import sys, numpy as np, pandas as pd
from pathlib import Path

sys.path.insert(0, '.')
from neo4j_layer.etl.transform import ConnectomeTransformer
from data.synthetic.generate_synthetic import AAL116_REGIONS

conn_dir = Path('data/synthetic/connectomes')
out_dir  = Path('data/processed')
out_dir.mkdir(exist_ok=True)

transformer = ConnectomeTransformer(region_names=AAL116_REGIONS)
all_edges   = []

files = sorted(conn_dir.glob('*.csv'))
print(f"Processing {len(files)} connectome files...")

for i, f in enumerate(files):
    parts     = f.stem.split('_')
    subject   = '_'.join(parts[:2])
    diagnosis = parts[2] if len(parts) > 2 else 'Unknown'
    matrix    = pd.read_csv(f, index_col=0).values.astype('float32')
    matrix    = transformer.regress_global_signal(matrix)
    matrix    = transformer.normalize(matrix, method='zscore')
    matrix    = transformer.threshold(matrix, threshold=0.3)
    edges     = transformer.to_edge_list(matrix, subject_id=subject, diagnosis=diagnosis)
    all_edges.append(edges)
    if (i+1) % 50 == 0:
        print(f"  {i+1}/{len(files)} done...")

edge_df = pd.concat(all_edges, ignore_index=True)
edge_df.to_csv(out_dir / 'edge_list.csv', index=False)
print(f"ETL complete: {len(edge_df):,} edges → data/processed/edge_list.csv")
PYEOF

cp data/synthetic/subjects.csv data/processed/subjects.csv
```

## Step 13 — Train: Multiple GPUs (DDP)

If your server has **2, 4, or 8 V100s**, use DistributedDataParallel for dramatically faster training:

```bash
# Set number of GPUs (replace 4 with your GPU count)
export N_GPUS=4

# Method A — use the launch script
N_GPUS=4 ./scripts/train_v100.sh

# Method B — run torchrun directly
torchrun \
    --standalone \
    --nproc_per_node=$N_GPUS \
    scripts/train_launcher.py \
    --config config/v100_config.yaml \
    --ddp \
    --skip-data-gen   # skip if data was already generated
```

**Expected speedup with DDP:**

| GPUs | Epoch time | 200 epochs |
|---|---|---|
| 1× V100 32GB | ~2 sec | ~7 min |
| 2× V100 32GB | ~1.1 sec | ~4 min |
| 4× V100 32GB | ~0.6 sec | ~2 min |
| 8× V100 32GB | ~0.4 sec | ~1.5 min |

> [!NOTE]
> DDP does not speed up GNNExplainer — that runs single-GPU on the main process only.

## Troubleshooting

### `RuntimeError: CUDA error: no kernel image is available for execution`

```bash
# Wrong CUDA wheel. Check your CUDA version and reinstall:
nvcc --version
# Then reinstall with matching wheel (cu118 / cu121 / cu124)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### `RuntimeError: Expected all tensors to be on the same device (DDP)`

```bash
# Make sure you're using torchrun, not python3 directly, for multi-GPU:
torchrun --standalone --nproc_per_node=4 \
    scripts/train_launcher.py --config config/v100_config.yaml --ddp
```

### `CUDA out of memory` on 16 GB V100

```bash
# In config/v100_config.yaml, reduce:
#   hidden_channels: 192  →  128
#   batch_size: 32        →  16
#   num_workers: 8        →  4
```

### `ValueError: BF16 is not supported on this device`

```bash
# V100 does NOT support BF16. In v100_config.yaml, ensure:
#   mixed_precision: fp16   (NOT bf16)
# Already set correctly — do not change.
```

### Training loss is NaN (FP16 instability)

```bash
# The GradScaler should handle this automatically.
# If NaN persists, reduce learning rate in v100_config.yaml:
#   learning_rate: 0.001  →  0.0005
# Or disable mixed precision:
#   mixed_precision: fp32
```

### `ImportError: cannot import name 'neo4j'` (name collision)

```bash
# Always run from project root:
cd ~/Neuro-Neo4j
python3 scripts/train_launcher.py --config config/v100_config.yaml
```
